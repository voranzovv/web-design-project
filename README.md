This project is a music player website with interactive features and smooth animations.

Audio Features

Play and pause songs
Next and previous buttons
Songs switch automatically when one ends
Progress bar shows how much of the song has played

Track List

Includes 5 of my songs
Click any song to play it
The current song is highlighted
Album image smoothly changes when songs switch

Animations & Effects

Floating music notes in the background
Moving bars (visualizer) when music plays
Play button has pulse animation
Buttons show ripple effect when clicked
Page loads with a smooth fade-in
Background colors slowly change

Accessibility

“Skip to content” link for easy navigation
Buttons have labels for screen readers
Keyboard support (Enter/Space to select songs)
Visual elements hidden from screen readers when needed

Subscribe Section

Email input with validation
On submit, a paper plane animation plays and shows “Sent!”

General

Clean and responsive design (works on mobile)
Uses proper HTML structure (header, main, footer)
Consistent colors using CSS variables
